# Business & domain naming — the SiteVerity family (final, locked)

Research pulled from four linked sessions building this HSE/construction-QA app portfolio for the
UAE market, deployed first on the Dubai Metro Blue Line project but designed to be configured per
organization from first-user setup, not built specifically for that one project:

- **SiteAssure** — former parent brand, Root Cause Navigator app. Visual identity (Sheet MK-00)
  recommended a "Strata" cross-section icon: layered bars reading "the real cause is the layer under
  the visible one." Navy (`#17456f`) / amber (`#b5701a`) blueprint-drafting identity system. Replaced
  by SiteVerity — see below.
- **SiteSnag** — sibling app, punch-list/defect-snagging. Its own mark review (Sheet MK-01)
  deliberately avoided the strata motif ("already belongs to a sibling product") and flagged the
  parent name as still open for debate — which it was, until now.
- **HSE Incident Investigation** — sibling app, renamed **SiteIncident** (an earlier round settled on
  SiteWitness; superseded — see below). Built in the same identity system "so the two apps read as
  one family without sharing a mark."
- **HSE AI Driven RCA** — the guided-RCA engine, renamed **SiteCause**. Shares a Supabase backend
  with SiteIncident and can link investigations to SiteIncident's cases — deliberate and permanent,
  since both start from a legally-notifiable HSE incident with real statutory authorities involved.
- **RCA Navigator** — sibling app, renamed **SiteResolve**. Starts from an NCR (Non-Conformance
  Report) — a procedural/quality record, not a statutory one — so it runs on its own separate
  backend, permanently un-linked from SiteIncident/SiteCause's data, even though its RCA screen
  follows the same appearance and interaction pattern as theirs.
- Market position benchmarked against Safetek (HITEK AI / Farnek group, Dubai), SmartQHSE, SafetyCulture,
  Cority, VelocityEHS, Benchmark Gensuite, Intelex, Safesite/SiteDocs, and Procore's Quality & Safety module.

## Locked: SiteVerity (parent brand) + SiteSnag / SiteIncident / SiteResolve / SiteCause

**SiteVerity** — no hyphen in the wordmark or in-app; the hyphen is domain-only
(`site-verity.com`, confirmed available and registered). Keeps the "Site" prefix already live across
the family, and "Verity" (truth) makes the same claim "Assure" was reaching for, pointed at the
product instead of the customer: SiteAssure promised a feeling, SiteVerity describes what the tools
actually produce — a verified, defensible account of what happened. No conflicting company, product,
or live trademark turned up in web, software-directory, and trademark-registry-indexed searches
(Justia Trademarks, Trademarkia).

**SiteIncident** (was HSE Incident Investigation, briefly SiteWitness) — a second naming pass traded
suggestive names for direct, descriptive ones across the family, on the reasoning that the buyers
(safety/quality managers) search and think in literal category terms. SiteIncident is the clean,
obvious result: no conflict found. (SiteWitness — named for the Parties/witness-statement capability
the competitive gap-analysis flagged as a genuine differentiator — is still a fine name if a more
suggestive direction is ever preferred back; also no conflict found.)

**SiteResolve** (was RCA Navigator) — closes the loop back to the NCR record (raise → RCA → CAPA →
back to NCR closure). Kept over the more literal **SiteNCR** specifically because "NCR" is a live,
actively defended trademark of NCR Corporation (NCR Voyix), a 36,000-employee enterprise
software/technology company — directly adjacent territory. No conflict found for SiteResolve itself.

**SiteCause** (was HSE AI Driven RCA) — names what the app does directly, fits the `Site` +
concrete-noun pattern next to the other three. Kept over the more literal **SiteRCA** specifically
because "RCA" is also a live, currently-owned trademark (Established Inc., since a 2024 sale by Voxx)
— lower collision risk than NCR since it's consumer electronics rather than software, but the letters
are so overloaded elsewhere (RCA connectors, RCA Records, Royal College of Art) that search
visibility would suffer regardless. No conflict found for SiteCause itself.

**In-app footer, same template, name substituted per app:**
`{AppName} - Part of the SiteVerity family — site-verity.com`

## Names to avoid, and why

| Name | Conflict found |
|---|---|
| **Strata / Substrata / TrueStrata / Veristrata** | Substrata is both a live LA construction firm (`substrata.com`) and a geotech software company; TrueStrata is a live Australian strata-management firm. "Strata" is also the actual legal term for jointly-owned building title in Australia and, via Jointly Owned Property law, the UAE — a real risk of reading as a property-management product to this exact audience. |
| **SiteLedger** | Registered trademark (Z and N Global Inc.) with two live products shipping under it already. |
| **FieldLedger** | At least four unrelated live companies use this exact name (federal contracting, utility billing, field service). |
| **Causeway / CauseWorks** | Causeway Technologies is a $167M-funded UK construction-software leader with 2,800+ customers — a direct collision. CauseWorks is a separate live nonprofit-tech firm. |
| **SnagTrack** | One character off from SnaggingTrack, a live, actively marketed "#1 snagging list and punch list software" — same category, high confusion risk. |
| **Sitecert** | Live, funded UK mobile-inspection-software company selling to the same buyer (lifting equipment, fall protection, rental-market inspections). |
| **Fieldproof** | Live construction-tech company (`fieldproof.io`) doing beta/UX testing for other construction-software vendors. |
| **Verascope** | Multiple live users of the exact name, including an active healthcare-AI-compliance platform at `verascope.ai`. |
| **Assuris / Assurio** | Assurio Software Inc. holds a live SaaS trademark; Intertek — a global inspection/certification company directly adjacent to this market — separately holds "INTERTEK ASSURIS." |
| **CoreCause** | Live nonprofit-fundraising product from CoreCommerce. |
| **SiteCase** | Taken multiple times over — an active website-builder product, an active iOS app, a Dutch company, and an old UK Ltd in liquidation. (Considered for the SiteIncident/SiteCause slots.) |
| **SiteNCR** | "NCR" is a live, actively defended trademark of NCR Corporation (NCR Voyix) — enterprise software/technology, directly adjacent to this market. Considered for the SiteResolve slot; ruled out. |
| **SiteRCA** | "RCA" is a live trademark (owned by Established Inc. since a 2024 sale by Voxx) and one of the most overloaded three-letter acronyms in English (connectors, Records, Royal College of Art). Considered for the SiteCause slot; ruled out. |

## Method and caveats

Every name above was run against general web search, software/company directories, and
trademark-database-indexed results. A name marked open means **no live company, product, or
registered mark turned up** — a green light to pursue, not a cleared registration.

Before committing to any name here:

1. Run an actual registrar check on the candidate domains — search-engine indexing lags real
   registration status, especially for a domain nobody has built a site on yet.
2. Run a formal trademark screen in the relevant classes (software/SaaS, business services) — USPTO
   TESS if selling into the US, and the UAE Ministry of Economy trade-name/trademark registers given
   the Dubai Metro / UAE-regulator focus already built into the product.
3. Check the UAE trade-name register specifically — this is where the "strata" collision above would
   bite hardest, since Dubai's Jointly Owned Property framework uses that exact term.
